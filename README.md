Ejercicio 03 - ADR

Esta rama contiene el trabajo correspondiente al Ejercicio 03 del proyecto Ganadapp, enfocado en la documentación de las decisiones arquitectónicas del sistema mediante Architecture Decision Records (ADR).

Los ADR documentan las principales decisiones tomadas durante el diseño y desarrollo de Ganadapp, incluyendo el contexto que motivó cada decisión, las alternativas consideradas y la solución seleccionada.

Esta documentación permite mantener un registro de las decisiones arquitectónicas del proyecto y facilita su comprensión, mantenimiento y evolución a lo largo del desarrollo.
