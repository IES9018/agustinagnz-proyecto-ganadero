Ejercicio 01 - Entrevista

Esta rama contiene el trabajo correspondiente al Ejercicio 01 del proyecto Ganadapp, enfocado en la etapa de relevamiento de requisitos mediante una entrevista.

En esta etapa se recopilaron y analizaron las necesidades del usuario, identificando los principales problemas, requerimientos y funcionalidades esperadas del sistema de gestión ganadera.

El contenido de esta rama sirve como base para definir y documentar los requisitos del sistema en las siguientes etapas del proyecto.
