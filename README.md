Ejercicio 02 - Diagrama C4 de Contexto

Esta rama contiene el trabajo correspondiente al Ejercicio 02 del proyecto Ganadapp, enfocado en la elaboración del diagrama C4 de contexto del sistema.

El diagrama representa a Ganadapp como sistema y muestra su relación con los principales actores y sistemas externos que interactúan con él. Su objetivo es proporcionar una visión general de los límites del sistema y de las interacciones existentes con su entorno.

Este modelo sirve como base para comprender la arquitectura general de Ganadapp y continuar con el desarrollo de los siguientes niveles de detalle del modelo C4.
